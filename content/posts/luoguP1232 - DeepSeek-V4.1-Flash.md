我已经读完洛谷题面（P1232 [NOI2013] 树的计数）和这篇博客，下面把这题的思路从头讲清楚。

先确认一下数据范围，避免把复杂度说错：
先说结论：这题的官方提示里给了关键性质——

> 对于任意三个节点 a,b,c，若 a、b 都是 c 的儿子，则 a、b 在 BFS 序和 DFS 序中的相对前后位置一致。

这句话是整个做法的基础。下面分步解释。

---

## 一、核心转化：高度 = BFS 序的"段数"

BFS 的一个基本性质：**同一层的节点在 BFS 序里一定连续**。反过来，如果能把 BFS 序切分成连续的若干段，每段恰好是同一层的所有节点，那么段数就是树高（根自成一层，高度从 1 开始）。

于是：
- 设 BFS 序有 n−1 个"缝"（第 i 个缝指 BFS 第 i 个点和第 i+1 个点之间）。
- 树高 = (切开的缝数) + 1。

由**期望的线性性**，我们不需要知道所有合法树，只要知道每个缝被切开的概率：

$$E[\text{高度}] = 1 + \sum_{i=1}^{n-1} P(\text{第 } i \text{ 个缝被切开})$$

而每个缝的概率只可能是三种：**必须切 (1)**、**不能切 (0)**、**可切可不切 (1/2)**。因为对"可切可不切"的缝，切与不切的合法树数量相等（存在一一对应），所以贡献恰好 0.5。

---

## 二、重标号技巧

因为只关心 BFS 序的"相对位置"，把 **BFS 序的第 i 个点重新命名为 i**。这样 BFS 序就变成 `1 2 3 ... n`，节点 i 的 BFS 位置就是 i。

设 `dfn[x]` = 节点 x 的 DFS 位置，`pos[i]` = DFS 第 i 个位置上的节点（即 dfn 的反函数）。

博客里那段 `pos[dfn[read()]]=i` 就是巧妙地借 `dfn` 当桥梁完成这次重标号，不用真的开新数组。

---

## 三、两类限制

### 限制 A：BFS 相邻点 i, i+1

由开头那条性质可推出：**同一层的点，在 DFS 中的先后顺序与 BFS 一致**。所以

- 若 `dfn[i] > dfn[i+1]`：i 和 i+1 不可能同层 ⟹ **必须切**，贡献 1。
- 若 `dfn[i] < dfn[i+1]`：可能同层（i+1 是 i 的兄弟），也可能不同层（i+1 是 i 的儿子），**无法确定**。

（为什么同层就同序？把同一层的点按"父节点在上一层的顺序"分组，每组在 DFS 中是一个连续块，归纳即证。）

### 限制 B：DFS 相邻点 a = pos[i], b = pos[i+1]

看它们在 BFS 中的位置关系，分三种：

| 情况 | 含义 | 结论 |
|---|---|---|
| `bfn[a] ≥ bfn[b]` | b 是 a 某个祖先的儿子 | 无额外限制 |
| `bfn[a] == bfn[b]−1` | b 是 a 的兄弟或儿子 | 无额外限制（可切可不切） |
| `bfn[a] < bfn[b]−1` | **b 一定是 a 的第一个儿子** | 区间 [a, b−1] 内的缝都**不能**成为"自由的 0.5 缝** |

第三种情况是重点：b 是 a 的第一个儿子，说明 BFS 序在 a 和 b 之间夹着的点，深度只可能是 `depth(a)` 或 `depth(a)+1`。可以证明：**这段区间里凡是能切的位置，其实都已经被限制 A 判定为"必须切"了**（一定存在 k∈[a, b−1] 使 dfn[k] > dfn[k+1]），所以这里只需要打个"禁止标记"，防止它被重复算成 0.5。

> 注意：打了禁止标记的缝如果本身是"必须切"，它的 +1 仍然有效——标记只是避免再加 0.5。

---

## 四、汇总算法

1. 答案初值 `ans = 1`；给第 1 个缝打"必须切"标记（根的独占一层，第 2 个点必在下一层）。
2. 对每个 BFS 相邻对 i, i+1：若 `dfn[i] > dfn[i+1]`，`ans += 1` 并给缝 i 打标记。
3. 对每个 DFS 相邻对：若 `pos[i] < pos[i+1]−1`，对缝区间 `[pos[i], pos[i+1]−1]` 打禁止标记（用**差分数组**维护）。
4. 扫一遍差分数组：没被标记的缝（既非必须切、也非禁止），`ans += 0.5`。
5. 输出 `ans`（保留三位小数）。

**样例演算**（n=5，DFS `1 2 4 5 3`，BFS `1 2 3 4 5`）：
重标号后 `dfn = [1,2,5,3,4]`（按节点），`pos = [1,2,4,5,3]`。
- 缝 1（点 1,2）：`dfn[1]=1 < dfn[2]=2`，不切；`pos[1]=1, pos[2]=2`，不是 gap → 缝 1 保留"必须切"（根单独一层）。
- 缝 2（点 2,3）：`dfn[2]=2 < dfn[3]=5`，不切；`pos[2]=2, pos[3]=4`，`2 < 4−1` → 禁止缝 2、3。
- 缝 3（点 3,4）：`dfn[3]=5 > dfn[4]=3` → `ans += 1`（=2），并标记缝 3。
- 缝 4（点 4,5）：都不触发 → 自由，`ans += 0.5`（=2.5）。
- 最后 `ans += 1` ⟹ **3.500** ✓

对应事实：这组序列恰有两棵树，高度分别是 3 和 4，平均 3.5——缝 4 恰好在一棵树里被切、另一棵里没切。

---

## 五、复杂度与细节

- 时间复杂度 **O(n)**，空间 O(n)（差分数组）；数据范围 **n ≤ 200000**，时间 1s，必须用快读。
- 洛谷上只输出一个数 `%.3lf`；博客代码里输出三个数（`ans±0.001`）是为 BZOJ 的特殊判题写的，不要照抄到洛谷。
- 博主自己也说"限制的充分性不会证"，只做了暴力对拍——这是道典型的**结论题**，考场上的做法就是记住/猜出这三个概率取值。

一句话总结：**把树高拆成 BFS 序的切分数，用期望线性性逐个缝统计概率——必须切给 1、必不切给 0、其余给 0.5，两个条件（BFS 相邻 dfn 逆序、DFS 相邻 BFS 间隔）分别制造"必切"和"禁止"标记。**
