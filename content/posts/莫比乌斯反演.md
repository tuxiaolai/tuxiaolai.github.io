## 定义
莫比乌斯函数，其定义为：
$$ \mu(n) = \begin{cases} 1, & n = 1 \\ 0, & n \text{ 有平方因子} \\ (-1)^k, & n \text{ 为 } k \text{ 个不同质数的乘积} \end{cases} $$
这里简单解释一下：  
对于一个 $n$，我们可以对它进行质因数分解，即 $n=\prod p_i^{x_i}$。若 $\exists \ x_i \geq 2$，则 $\mu(n)=0$，否则设 $n$ 能够被分解成 $k$ 个质数的乘积，则 $\mu(n) = (-1)^k$。

## 性质
莫比乌斯函数有以下优美的性质：
### 1. 积性函数
> 积性函数的定义：在数论中，若函数 $f(n)$ 满足 $f(1) = 1$，且 $f(xy) = f(x)\,f(y)$ 对任意互质的 $x, y \in \mathbf{N}^*$ 都成立，则 $f(n)$ 为**积性函数**。

不难发现，莫比乌斯函数也是一个积性函数。
#### 证明
对于 $x, y \in \mathbf{N}^*$，我们将它们进行质因数分解：$x=\prod_{i=1}^t p_i^{k_i},y=\prod_{j=1}^h p_j^{m_j}$。  
当两者互质时，$x$ 与 $y$ 显然没有相同的质因子。此时分以下两种情况：
1. $\mu(x) \times \mu(y)=0$，这就意味着 $k_i$ 和 $m_j$ 中存在一个数 $\geq 2$。那么它们的乘积 $xy$ 自然也会有 $\geq2$ 的质因子指数，所以 $\mu(xy) = \mu(x) \times \mu(y)=0$。
2. 否则，$xy$ 就应当有 $t+h$ 个质因子，根据莫比乌斯函数的定义，$\mu(xy) = (-1)^{t+h} = (-1)^t \times (-1)^h =\mu(x) \times \mu(y)$。
   此外，当 $x$ 与 $y$ 不互质时，两者有共同质因子，则 $xy$ 必定存在 $\geq 2$ 的质因子指数，所以 $\mu(xy)=0$。

整合以上证明，我们得出以下结论：
$$
\mu(xy)=\mu(x)\times\mu(y) \times [\gcd(x,y)=1]
$$
### 2. 莫比乌斯函数求和公式
$$
\sum_{d\mid n} \mu(d) = [n=1]
$$
这个公式非常重要，表示将所有 $n$ 的因数 $d$ 的 $\mu(d)$ 相加，其结果在 $n=1$ 时为 1，否则为 0。
#### 证明
对于 $n=\prod_{i=1}^k p_i^{x_i}$，由于我们取多个同一质因子组成因数时莫比乌斯函数值为 0，对求和没有贡献，因此我们只需要考虑每个质因子取 0 或 1 个的情况。  
接下来就很简单了，我们要在 $k$ 个质因子中选择一些组成因数。若我们要选择 $i$ 个质因子，其莫比乌斯函数为 $(-1)^i$，而选择的方案数则为 $C_k^i$，所以
$$
\sum_{d\mid n} \mu(d) = \sum_{i=0}^k C_k^i (-1)^i
$$
根据二项式定理，我们得出
$$
\sum_{d\mid n} \mu(d) = (1+(-1))^k = [k=0] = [n=1]
$$
### 3. Dirichlet 卷积
先来介绍一下什么时 Dirichlet 卷积。
数论函数 $f(n)$ 和 $g(n)$ 的 **Dirichlet 卷积**，记作 $f \ast g$，定义为数论函数 $$(f \ast g)(n) = \sum_{k \mid n} f(k)\,g\!\left(\frac{n}{k}\right) = \sum_{k\ell = n} f(k)\,g(\ell).$$
它有一个单位函数 $\varepsilon$，使得 对任意数论函数 $f$，都有 $\varepsilon \ast f = f\ast \varepsilon = f$。根据定义不难证明：$\varepsilon(n)=[n=1]$。再联系上文的求和公式，可以得出 $\varepsilon = 1 \ast \mu$。

## 求法
根据线性筛的过程与莫比乌斯函数的定义，我们可以用像这样 $O(n)$ 地求出 $1 \sim n$ 的莫比乌斯函数值：
```cpp
int n;  
  
int mu[N + 10];  
  
bitset<N + 10> vis;  
vector<int> pri;  
  
void get_mu() {  
    mu[1] = 1;  
    for (int i = 2; i <= n; i++) {  
        if (!vis[i]) {  
            pri.push_back(i);  
            mu[i] = -1;  
        }  
        for (int j: pri) {  
            if (1ll * i * j > n) {  
                break;  
            }  
            vis.set(i * j);  
            if (i % j == 0) {  
                mu[i * j] = 0;  
                break;  
            }  
            mu[i * j] = -mu[i];  
        }  
    }  
}
```
## 莫比乌斯反演
设 $f(n), g(n)$ 是两个数论函数。那么有 $$ f(n) = \sum_{d \mid n} g(d) \iff g(n) = \sum_{d \mid n} \mu\!\left(\frac{n}{d}\right) f(d)$$
## 证明
利用 Dirichlet 卷积，命题等价于 $$ f = 1 \ast g \iff g = \mu \ast f$$ 利用 $1 \ast \mu = \varepsilon$，在左式的等号两侧同时对 $\mu$ 做卷积，就得到 $$ f \ast \mu = (1 \ast g) \ast \mu = (1 \ast \mu) \ast g = \varepsilon \ast g = g$$
## Dirichlet 前缀和/差分
OI-Wiki 将它放在莫比乌斯反演一栏，但我至今不知道它与莫比乌斯反演有什么关系，有没有大佬能解释一下的。

### 定义
$g(n)$ 为数论函数，它的 Dirichlet 前缀和就是：
$$
f(n) = \sum_{d\mid n} g(n)
$$
反过来则是 Dirichlet 差分。  
不少地方提到这本质上就是高维前缀和，这里我进行详细解释：  
我们先考虑 $n=p^x$ 的情况，
$$
f(n)=\sum_{i=0}^x g(p^i) = f(\frac{n}{p}) + g(p^x)
$$
这显然就是对 $p$ 进行一个前缀和。  
此时我们再加入另一个质因子 $q$，$m=p^xq^k$。  
我们设 $h(i,j) = \sum_{l=1}^i f(p^lq^j)$，这个可以像前面一样看作是对 $p$ 的前缀和。  
那么
$$
f(m) = \sum_{i=1}^x \sum_{j=1}^k g(p^iq^j) = \sum_{j=1}^k h(x,j)
$$
实际上就是对 $h$ 做一遍 $q$ 的前缀和
